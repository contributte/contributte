# All

## Github CLI

- Use `gh` cli to manager repository
- Pass github repo to `gh` cli

## Coding style

- Read `specs/SYNTAX.md` before writing or reviewing PHP: dialect A for Contributte repositories, dialect B for Nette
- Follow the repository's own convention where it already has one ("local convention wins")
- `specs/LIBRARY.md` and `specs/SKELETON.md` describe repository layout and tooling; `specs/fixtures/` holds the
  golden files that must stay green under `contributte/qa`, phpstan level 9, Nette Tester and DressCode
